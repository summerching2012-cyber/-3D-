# 独孤信多面印 V3 · 文物表面参照版

双击 `打开模型.html`，使用 Edge 或 Chrome。鼠标左键拖拽旋转、滚轮缩放、右键平移，右侧索引可逐面查看。模型、两种表面和13张参考照片均内嵌，不依赖联网。

## 本次变化

- 保留 V2 的26个面、印位、文字坐标系与六个实物对照视角。
- 默认开启“文物照片表面”：将陕历博官网藏品照片按共享棱角映射到7个可见面。黑色表面上的红色残留、裂隙、擦损与反光来自照片，不使用随机裂纹替代。
- 关闭该开关即可回到 V2 几何对照。红色填痕与表面微纹两个开关只在几何模式启用，避免误以为能把照片中的颜料和磨损独立分离。
- “馆藏参照视角”恢复面向密、大司馬、臣信啓事的观察方向。
- 文物表面模式使用略宽的圆角作为理想化外形处理，不代表原件边缘测量。

照片表面的字迹也来自照片，因此这些面不再叠加普通楷体凹刻，避免双重字影；其字迹、裂隙并无实测立体深度。关闭照片模式后可看完整14面几何凹刻，但其字体仍为近似（包括“印”字），不能当作原文物笔迹复刻。

源图只有517×539像素，放大后细节有限。表面映射是手工角点近似；原件的非平面、圆角和透视不能完全匹配理想26面体，部分棱边和斜面有拉伸。照片原有反光保留，改变侧光不会让原照片反光移动。这是可旋转的照片参照模型，不是全周摄影测量或高精度文物扫描。

复制品照片仅用于相邻印位与朝向核对；不把复制品表面当作馆藏磨损。`7.对比图“印”字.jpg` 已一并收入参考图；本轮未逐笔重绘“印”的字形。

## 文件与验证

- `独孤信多面印.blend`：V3照片表面模型，图像已打包。
- `独孤信多面印.glb`：V3模型；`几何对照.glb`：V2完整刻字对照。
- `preview.png`：Blender渲染；`viewer-aged.png`、`viewer-clean.png`：实际浏览器截图。
- `layout-check.json`：六组照片邻接关系、14个字向基底；`model-check.json`：实体非流形边为0。
- `viewer-check.json`：模式切换、拖拽缩放、逐面导航、照片载入与浏览器错误检查。
- `delivery-check.json`：V2基线不变、源照片不变及交付输出哈希。

构建脚本为 `build_model.py`；网页源文件为 `viewer.js`、`template.html`、`package_viewer.py`。使用原有 Three.js 0.180.0、esbuild 0.25.10 和 Blender 5.2.2。许可证见vendor目录。`make_v3.py` 和 `update_viewer.py` 从相邻V2目录派生构建脚本；交付文件夹可直接运行现成的build_model.py和package_viewer.py。

V1、V2和原始输入不覆盖。版本记录保存在本地state目录；正式行动记忆索引无法打开，未同步，不影响交付。
